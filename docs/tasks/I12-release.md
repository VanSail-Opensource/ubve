Source selection, actual conformance, artifact build, decoded pixels/PCM/metadata, browser execution, complete pipeline, physical output and endurance are separate statuses. Native/GPU results skipped by user request are DEFERRED_NOT_QUALIFIED. The current Linux CPU component evidence cannot qualify a missing Windows/macOS/iOS/iPadOS/Android endpoint. A MIME/API query or registry absence is not a performance/native-absence proof.

## Strict gate

Full-60 requires genuine 60/1 at 1× with source precision/resolution, HDR10 mapping/metadata, 10-bit samples, exact decoder PCM, complete subtitle semantics/fonts and timeline/channels. Performance-120 requires genuine 120/1 at 1×, no temporal reduction, a named reference-validated transform, exact decoded channel PCM and required subtitle content/timing. Optional Dolby Vision adds a real separate rendering check; HDR10 does not imply it.

Require at least five independent sustained trials: 1,800 active seconds per Windows/macOS trial and 3,600 per mobile-family trial. Every eligible source picture is on time; late/dropped pictures and audio-underrun samples are zero, final steady-window rate is at target, memory/foreground are verified and all trials pass. Counting only submitted pictures, repeats/interpolation or decoder outputs cannot satisfy the denominator.

PASS_PIPELINE_ONLY is limited to the verified browser pipeline. PASS_EXACT_CONFIGURATION requires physical HDR/audio/subtitle output, active display refresh at least target and physical A/V sync p95 ≤ 20 ms / max ≤ 50 ms. Use the evaluator's exact conditions rather than a copied approximate threshold. An eight-hour endurance claim still needs an actual 28,800 s trace; five shorter trials do not establish that additional claim.

## Assets and production activation

The loader requires exact owned artifact/ABI and matching qualified profiles. Production provider lists remain empty now. Known experimental binary hashes in the provider policy are build provenance, not complete player support. Native components record actual endpoint/browser identity rather than an invented inaccessible OS decoder hash.

Ship self-hosted versioned JS/WASM/workers/fonts with integrity, ABI, configuration, source patches and notices. Standard and isolated documents have explicit policies; secure context/crossOriginIsolated are runtime conditions, not a Vue toggle. A document change may require local source reselection. No mandatory backend, installed helper, proxy or hidden codec/font CDN.

Check missing/mismatched assets, stale caches, blocked workers, unsupported isolation, partial initialization, all descendant resources and failed shutdown. Registration alone does not prove decoder-only packaging or satisfy licenses. Keep FFmpeg/libmedia/dav1d/JASSUB source/build/license obligations tied to exact distributed artifacts. Production source remains bounded; never package a whole-movie VFS benchmark as streaming implementation.
