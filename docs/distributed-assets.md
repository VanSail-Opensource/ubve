# Distributed browser asset audit

This is a static packaging inventory, not a licensing determination or playback qualification. The baseline Vite build emitted 38 files, including 20 self-hosted vendor files. The audited artifact is the whole `apps/vue-player/dist` directory. Files served from it count even if the current player normally selects another copy. An npm license field, a file hash, a source map, and an exact corresponding-source package are different evidence.

The current build stages exact installed npm and disc notice files into `vendor/notices/` with a hash manifest. The table records baseline observations before that improvement. Run the audit on the current artifact for byte-matched notice presence. A copied notice does not resolve every bundled component, corresponding-source recipe or the project's own distribution choice.

## Reproduce the inventory

From the repository root, use the pinned install and build, then inspect the artifact.

```sh
npm ci --ignore-scripts
npm run build
node scripts/audit-distributed-assets.mjs
```

The auditor reads the emitted Vite maps, verifies actual libmedia worker module contributions by rebuilding the esbuild worker, compares exact installed notice files with emitted files, and verifies the staged audio WASM hashes from inert JavaScript AST extraction without executing the workers. It also checks the disc source archive pins and duplicate JASSUB copies. An optional positional argument points at another already built static distribution. It reports standalone notice matches and does not infer their absence from lack of an inline comment or the reverse. It does not check that remote source links are published or that compiled routines can be replaced or reproduced.

I12 should bind every runtime artifact to its manifest and exact notice/source/rebuild materials before public deployment. Regenerate the inventory after any change to pins, normalization, Vite emitted assets, or deployment packaging. Keep the strict playback release gate separate. Neither source material nor a complete notice directory establishes 60/120 fps performance.
