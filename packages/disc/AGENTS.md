# Disc adapter

Read root AGENTS.md. Only local unencrypted UDF and explicitly selected linear angle-zero BDMV titles are eligible. No decryption, JVM, menu or installed helper. Source archives, exact patches, build recipe and resulting assets must stay linked by hashes. Native work here is build-time WASM compilation, not an installed runtime.

C operates inside one owning Worker. FileReaderSync reads at most 1 MiB per callback; cancellation during a synchronous C call requires the host's finite watchdog and termination. Do not claim immediate physical abort. Public libbluray times are already in 90 kHz units. Keep strings/bigints; do not reinterpret them as raw MPLS 45 kHz fields.

Folder lookup is case-insensitive only after rejecting ambiguous duplicates and paths. UDF reads preserve extents and never extract the complete ISO. Whole-title playback remains unqualified until clip trims, track transitions and references have passed through the actual player.
